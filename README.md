## Description
 
This is a repository for the final project of CS4515 CGA (Computer Graphics and Animation) course at TU Delft, built with CMake. The project is a simple 3D graphics application in C++ & OpenGL. 

## Dependencies

- [GLAD](https://github.com/Dav1dde/glad): loading OpenGL functions
- [GLFW](https://github.com/glfw/glfw): context creation & windowing
- [glm](https://github.com/g-truc/glm) (OpenGL Mathematics): math libraries 
- [tinyobjloader](https://github.com/tinyobjloader/tinyobjloader): parsing and loading 3D model .obj files
- [Dear ImGui](https://github.com/ocornut/imgui): debug UI
